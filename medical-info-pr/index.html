HOW IT WORKS

やることは、3つだけ。

プロンプトの仕組みを知らなくても大丈夫です。入力して、コピーして、同じChatGPTで画像を1枚ずつ作ります。

01
✎

参考URL、入れたい内容、対象者、ページ数を入力します。

02
✦

MASTERで設計

まず1本の記事として調査・編集し、必要な枚数に自然に分けます。

03
▣

RENDERで完成

同じ会話でRENDERを繰り返し、未生成区間を1枚ずつ画像化します。

FOR PUBLIC USE
公開して使うことを前提にしています。
このWebサイトは静的サイトとして動作します。独自APIやデータベースは使いません。入力保存をOFFにしている間、フォーム内容をブラウザの永続領域にも保存しません。

        
  • アクセス解析・広告・Cookieなし
  • キーボード操作とフォーカス表示に対応
  • 動きを減らすOS設定を尊重
  • スマホのノッチ・ホームバー領域を考慮
